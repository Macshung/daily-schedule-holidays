# 每日行程 · Daily Schedule — 公眾假期表

呢個 repository 只放一個檔案 `holidays.json`：**中國大陸、台灣、韓國**嘅公眾假期，俾「每日行程」app 每 7 日讀一次。
（香港、英國、日本由 app 直接喺政府網站下載，唔喺呢度。）

- 每個地區列出嘅年份，會取代 app 入面同一年嘅內置資料；冇列出嘅年份照用內置資料。
- App 會逐個地區檢查：只要某地區有一個錯（日期唔存在、名稱漏咗、某年少過 5 日），成個地區都唔用，照用之前嘅資料。
- 更新流程：排程任務喺各地政府公布新一年假期後整理資料、開 Pull Request，**主人過目之後先 merge**。

## 格式

```json
{
  "format": 1,
  "updated": "YYYY-MM-DD",
  "regions": {
    "cn": { "2027-01-01": { "zh": "元旦", "en": "New Year's Day", "ja": "元日（中国）", "ko": "원단(새해)" } },
    "tw": { },
    "kr": { }
  }
}
```

- `zh` 用繁體字（簡體由 app 自動轉換）；`en`、`ja`、`ko` 都要有。
- **中國大陸**：列出放假期間每一日；調休上班日唔列。
- **台灣**：節日當日 + 補假／調整放假日，補假名稱加「（補假）」／ "(substitute day)" ／「（振替休日）」／ "(대체 휴일)"。
- **韓國**：공휴일 + 대체공휴일，補假名稱 `ko` 寫成「대체공휴일(…)」，其他語言同台灣一樣加補假字眼。

## 改完之後

```
node check.mjs
```

列出每年每日（連星期幾）俾你核對；有問題會顯示 PROBLEMS 並且唔好發佈。

## 資料來源

- 中國大陸：國務院辦公廳《關於 XXXX 年部分節假日安排的通知》（gov.cn／新華網）
- 台灣：行政院人事行政總處《政府行政機關辦公日曆表》（dgpa.gov.tw）
- 韓國：우주항공청·한국천문연구원《월력요항》、인사혁신처《관공서의 공휴일에 관한 규정》
